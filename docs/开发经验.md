## 1. 项目定位

- Minecraft 1.20.1，Fabric 与 Forge 双端。
- 玩法：按倒计时把若干区域整块替换成随机方块；支持命名区域、延迟、Bossbar、状态持久化。
- 后续扩展：维度锁定、选区魔杖、方块池界面、方块池 ACL、按存档隐藏列表、键位 0 玩法主界面。
- 明确**不引入 Architectury**；共享层是普通 `common/` Java 源目录，两端各自保留映射适配层。

## 2. 目录与职责

```text
common/src/main/java/yifei/rsl/common/   纯 Java 共享逻辑，禁止 import net.minecraft.*
src/main/java/yifei/rsl/                 Fabric 适配层
forge/src/main/java/yifei/rsl/           Forge 适配层
common/src/main/resources/rsl/default_blocks.json   内置 269 种方块 id
```

### common

- `config/`：`RslSettings`、`RslState`、`AreaSpec`、`AreasFile`、`ConfigCodec`、`PoolAccess`、`PoolAccessEntry`、`HiddenBlocks`、`HiddenBlocksFile`、`BlockId`、`DimensionId`、`BlockMutationResult`。
- `block/`：`BlockId` 语法校验、`DefaultBlocks` 读取内置池。
- `world/`：`FillCursor`，区域遍历与世界高度裁剪。
- `ui/`：`PoolLayout`、`PoolSelection`，不依赖 MC 的纯布局/选择差异逻辑。
- 测试：`common/src/test/java`，由 Fabric 的 Gradle 测试任务执行。

### Fabric

- 入口 `src/main/java/yifei/rsl/RandomSkyBlockIsland.java`。
- 平台 `ModConfig` 负责注册表解析、`FabricLoader` 配置目录、Gson 持久化、ACL、保存回滚。
- 网络 `BlockPoolNetwork`、`WandNetwork`；客户端 `RslClient`、`BlockPoolScreen`、`GameplayScreen`、`AreaWandScreen`。
- 事件：`ServerPlayConnectionEvents` 处理 JOIN/DISCONNECT，`ServerLifecycleEvents` 处理停止。

### Forge

- 入口 `forge/src/main/java/yifei/rsl/RandomSkyBlockIsland.java`。
- `ForgeRegistries`、`FMLPaths.CONFIGDIR`、`SimpleChannel`、`RegisterCommandsEvent`。
- 客户端类必须通过 `DistExecutor.unsafeRunWhenOn(Dist.CLIENT, ...)` 或 `ClientConfigRegistration` 隔离，避免专用服务器解析客户端类。
- `forge/build.gradle` 通过 `sourceSets.main.java.srcDir '../common/src/main/java'` 复用 common。

## 3. 构建与环境

### 必要环境

- Gradle 由各端 wrapper 提供：根目录 Fabric Gradle 9.5.1，`forge/` Forge Gradle 8.8。
- **Gradle 运行 JVM 必须是 JDK 21**：根 `gradle.properties` 仍固定
  `org.gradle.java.home=C:/Program Files/Java/jdk-21`；这是 Loom 1.17 的硬要求，不是项目代码要求。
- 项目编译目标 Java 17（`options.release=17` / Forge toolchain 17）。

### 常用命令

```powershell

.\gradlew.bat clean test build --console=plain

# Forge：构建
cd forge
.\gradlew.bat clean build --console=plain
```

- 产物：`build/libs/rsl-fabric-1.0.0.jar`、`forge/build/libs/rsl-forge-1.0.0.jar`。
- Fabric 测试报告：`build/test-results/test/*.xml`。
- 只改 common 时也要跑 Forge build，确认共享源目录仍能编译。

### 依赖

- Fabric：Loom `1.17-SNAPSHOT`、Fabric API `0.92.11+1.20.1`、Cloth Config `11.1.136`、Mod Menu `7.2.2`；Cloth/Mod Menu 是可选 UI 依赖。
- Forge：Forge `47.4.22`、Cloth Config `11.1.136` 可选；Catalogue 只是开发运行时的本地可选依赖。
- 不要重新引入 `libs/` 本地 jar 作为编译依赖；干净克隆必须能靠 Maven 构建。

## 4. 双端同步约定

### 必须成对修改

- 任何 common 行为变更：Fabric/Forge 的 `ModConfig`、`IslandGame`、`AreaCommand`、`BlocksCommand`、`StatusCommand`、`ReloadCommand`、语言文件都要检查。
- 新增命令：两端命令树、权限谓词、反馈消息、语言键必须一致；`ParityTest` 会扫描命令 literal/argument 与 lang key 集合。
- 新增语言键：Fabric 与 Forge 四份文件（各 zh_cn/en_us）都要加；Forge 通常直接从 Fabric 复制后做哈希/键集合校验。
- 新增网络包：Fabric 用 `Identifier` + `PacketByteBuf`，Forge 用 `SimpleChannel`；字段顺序必须在两端一致。

### 映射差异速查

| 语义 | Fabric | Forge |
|---|---|---|
| 命令调度 | `CommandManager` | `Commands` |
| 命令源 | `ServerCommandSource` | `CommandSourceStack` |
| 文本 | `Text` / `MutableText` | `Component` |
| 玩家异常 | `getPlayerOrThrow()` | `getPlayerOrException()` |
| 世界 | `ServerWorld` | `ServerLevel` |
| 方块位置 | `BlockPos` | `BlockPos` / `MutableBlockPos` |
| 注册表 | `Registries.BLOCK` | `ForgeRegistries.BLOCKS` |
| 标识符 | `Identifier` | `ResourceLocation` |
| 配置目录 | `FabricLoader.getConfigDir()` | `FMLPaths.CONFIGDIR.get()` |
| 反馈 | `sendFeedback` | `sendSuccess` |
| 客户端类隔离 | client entrypoint | `DistExecutor` / `Dist.CLIENT` |

### 常见编译错误

- Fabric 命令类常缺 `net.minecraft.registry.Registry` import。
- Forge `CommandSourceStack` 没有 `getPlayerOrThrow()`，用 `getPlayerOrException()`。
- Fabric `Screen` 没有 `onClose()`，覆写 `close()` 并调用 `super.close()`。
- Forge `MutableBlockPos` 可复用，但不要跨区域/跨 tick 保存可变对象。
- `ResourceLocation(String,String)` 在 Forge 1.20.1 有弃用警告；可继续用，但新代码优先 `new ResourceLocation(namespace, path)` 的等价形式或已有工具方法。

## 5. 配置与持久化

### 文件分工

| 文件 | 作用 | 位置 |
|---|---|---|
| `randomskyblockisland.json` | 全局设置、初始默认区域、方块池、ACL | `config/` |
| `randomskyblockisland.state.json` | 运行状态、倒计时 | `config/` |
| `rsl_areas.json` | 当前存档的默认区域、命名区域、`activeDimension` | `<存档>/` |
| `rsl-hidden-blocks/<hash>.json` | 客户端隐藏方块列表 | 客户端 `config/` |
| `rsl-hidden-blocks.json` | 旧版全局隐藏列表，仅作迁移种子 | 客户端 `config/` |

### 配置 v2

- `RslSettings`：`transformDelaySeconds`（180，1–86400）、`maxAreaVolume`（65536，1–4,000,000）、`blocksPerTick`（8192，256–1,048,576）、`broadcastMode`（`all`/`nearby`/`summary`，默认 `all`）、`broadcastRadius`（64，1–512）、`defaultArea`、`allowedBlocks`、`poolAccess`。
- `RslState`：`isRunning`、`secondsRemaining`；未运行时 `secondsRemaining` 清零。
- `AreasFile`：`defaultArea`、`areas`、`activeDimension`；旧文件没有 `defaultArea`/`activeDimension` 时按兼容处理。
- `ConfigCodec` 负责：v1 迁移、损坏文件备份、原子写（tmp + `ATOMIC_MOVE`）、旧 `areas` 数组迁移、缺失 `allowedBlocks` 填默认池。
- 旧配置迁移会生成 `randomskyblockisland.v1.bak.json`；不要在迁移时删除旧文件。

### 写盘策略

- 设置只在变更时写；运行状态每 10 秒 + 开始/停止/变换时写，不要恢复“每秒全量写配置”。
- 写设置失败必须返回 `false`/`IO_ERROR` 并回滚内存，不要只记日志。
- 写存档区域失败要回滚原区域对象；`replaceArea` 也要原子替换。
- 不要在 `saveConfig` 里顺手改倒计时；旧代码的 `updateDelay` 副作用已移除。

### 方块池

- `allowedBlocks` 存**字符串 id**；运行时解析为 `Block`/`BlockState`。
- 未知/缺失 id 保留在配置和 `blocks list` 中，不要静默删除；它们不参与随机。
- 池空时 `/start` 拒绝；运行中不允许通过 remove/clear 清空到 0。
- 池上限 4096；批量网络一次最多 512 个变更。
- 默认池在 `common/src/main/resources/rsl/default_blocks.json`，当前 269 项；`blocks reset` 恢复它。

## 6. 区域与维度

- `AreaSpec` 坐标在 common 层规范化（min/max 排序）；体积用 `long` 饱和计算，避免 int 溢出。
- 区域上限由 `maxAreaVolume` 控制；添加/加载时校验，非法区域跳过并告警。
- `FillCursor`：x 外层、y 中层、z 内层；世界高度裁剪；`total` 饱和。
- 变换用 `activeDimension` 查找世界；找不到时提示 `dimension_missing` 并停止，不要静默回主世界。
- `/start` 锁定执行者当前维度并写入 `<存档>/rsl_areas.json` 的 `activeDimension`。
- 运行中：`start`、`reset`、`delay`、区域修改在非锁定维度被拒；`stop`、`status`、`reload`、`blocks`、`area initial` 放行；控制台放行。
- 区域坐标本身维度无关；当前没有“每维度一套区域”的功能。
- 每存档默认区域独立；全局 `defaultArea` 只在新存档首次加载时播种。

## 7. 方块池 ACL（独立于 OP 4）

- 原版 `hasPermissionLevel(4)` 无法表达“4 级 OP 也不能打开”；因此方块池 UI 和 `blocks` 命令完全走模组 ACL。
- `RslSettings.poolAccess` 存 `PoolAccessEntry{uuid,name,role}`，角色 `OWNER`/`EDITOR`。
- 控制台、单机房主始终 Owner；`/randomskyblock access list|grant|grantowner|revoke` 由 Owner/控制台/房主管理。
- 未授权请求复用 `PoolMutationResult` 返回 `rsl.pool.no_permission`，客户端关闭界面；服务端不发送快照。
- 其他玩法命令仍用 4 级权限；`status` 对所有玩家开放。
- 不要把 `blocksPermissionLevel` 加回来；它已从 settings 移除。

## 8. 客户端 UI 与键位

- 方块池：默认快捷键 `B`，`BlockPoolScreen`。
- 玩法主界面：默认快捷键 `0`，`GameplayScreen`；按钮只发送原 `/randomskyblock ...` 命令，权限/维度/ACL 仍由服务端校验。
- 选区魔杖：`rsl:selection_wand`，木棍派生 16×16 纹理；右键选点/编辑，Shift+右键清空。
- `PoolLayout`：动态行列、两行 footer、居中页码、右上角关闭；7 个按钮。改布局必须同步 Fabric/Forge 并更新 `PoolLayoutTest`。
- 隐藏列表：客户端按存档/服务器上下文保存；隐藏只影响本地方块池渲染，不删除模组方块、不改服务端随机池。
- 图标渲染不引入 JEI/REI 硬依赖；用注册表 + `ItemStack`/`BlockRenderManager`，无物品方块画色块。

## 9. 测试与验收

### 自动测试

- `common/src/test/java` 覆盖：配置 codec/迁移、AreaSpec、FillCursor、BlockId、DimensionId、PoolAccess、PoolSelection、PoolLayout、ParityTest。
- 运行：`.\gradlew.bat test --console=plain`；完整：`clean test build`。
- `ParityTest` 检查两端 lang key 集合与命令 literal/argument 集合；新增命令/语言键必须同步，否则测试失败。
- 当前基线：88 tests、16 个 test XML、0 failures（Fabric）。

### 手动验收

1. 旧 v1 配置能加载并生成 `.bak`；旧 `areas` 数组能迁移。
2. `/start` 锁定当前维度；其他维度执行受限命令有明确提示。
3. 默认区域按存档独立；`area initial` 只改全局初始值。
4. 方块池添加/删除/清空/重置；未授权 4 级 OP 打不开界面。
5. 隐藏/不可见池/刷新；关闭重开、切换存档后列表独立；旧全局文件首次迁移。
6. 键位 `B`、`0` 不与魔杖右键冲突；命令仍可用。
7. Fabric/Forge clean build，Fabric tests 全过。

## 10. 常见坑（按踩坑频率）

1. **只改一端**：Fabric 编译过不代表 Forge 过；`Text`/`Component`、`ServerWorld`/`ServerLevel` 等映射会漏。
2. **把客户端类带进服务端**：Forge 用 `DistExecutor` 包一层；Fabric 用 client entrypoint。
3. **每秒写配置**：旧版 `IslandGame.tick` 每秒 `saveConfig`；现在只每 10 秒写 state，设置变更才写 settings。
4. **空方块池**：`random.nextInt(0)` 崩溃；`start` 和 `transform` 都要守卫。
5. **区域坐标未规范化**：min/max 反了会空遍历或算错体积；统一走 `AreaSpec.normalized()`。
6. **int 体积溢出**：大区域用 `long` 饱和；不要用 `int` 乘。
7. **隐藏列表放服务端**：它是客户端显示过滤，不能写进 `randomskyblockisland.json` 或影响随机池。
8. **ACL 用 OP 等级**：会违背“4 级 OP 也必须授权”的需求；必须走 `poolAccess`。
9. **reload 不回滚**：设置/区域/activeDimension 读失败时要恢复旧值，否则半套配置。
10. **语言键只加 Fabric**：Forge 语言文件是独立资源，`ParityTest` 会抓。
11. **JDK 版本**：Gradle 运行 JVM 是 21，项目 release 是 17；不要混。
12. **Forge 本地 `libs/`**：不是提交依赖；干净克隆应与本地 jar 无关。

## 12. 已知限制

- `gradle.properties` 固定 `org.gradle.java.home` 为 JDK21；换机器需改路径。
- 未做实际客户端进服完整手测；构建/单测通过不等于 UI 交互全部验证。
- 隐藏列表是客户端本地的；不同玩家/不同客户端不会共享。
- 区域坐标维度无关；没有每维度独立区域。
- 没有 CI；双端构建需手动跑。
- Forge 仍有 `ResourceLocation(String,String)` 弃用警告（非错误）。
- `dsh-flash-presets` 的 persona 修改属于本机 DSH 环境，不属于本项目构建产物；预设包升级可能覆盖。
